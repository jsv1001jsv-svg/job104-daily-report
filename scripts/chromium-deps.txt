# Chromium (Playwright) 在 Debian 13 (trixie) 上的執行期系統相依。
#
# 為什麼要自己列，而不是用 `playwright install --with-deps`：
# 該指令寫死 Ubuntu 的字型套件名，在 Debian 上會失敗（見 Dockerfile 註解）。
#
# 抽成獨立檔案是為了讓「需要哪些套件」這件事可被 diff、可被 review，
# 而不是埋在一行很長的 RUN 指令裡。
#
# ⚠️ 升級基底 image 的 Debian 版本時要重新驗證。快速檢查：
#   docker run --rm python:3.12-slim sh -c \
#     "apt-get update -qq && xargs -a - apt-get install --simulate" < scripts/chromium-deps.txt
#
# t64 後綴是 Debian 13 起的 64-bit time_t 轉換所致，較舊版本不帶此後綴。

# --- 圖形與繪製 ---
libgbm1
libdrm2
libcairo2
libpango-1.0-0

# --- X11 ---
libx11-6
libxcb1
libxext6
libxcomposite1
libxdamage1
libxfixes3
libxrandr2
libxkbcommon0

# --- 安全性與網路 ---
libnss3
libnspr4

# --- 無障礙介面（Chromium 啟動時必需，即使 headless）---
libatk1.0-0t64
libatk-bridge2.0-0t64
libatspi2.0-0t64

# --- 音訊（headless 也會初始化）---
libasound2t64

# --- 列印 ---
libcups2t64

# --- 字型：缺少會導致中文渲染為方框 ---
fonts-liberation

# --- 虛擬顯示器：讓 Chromium 能以「有頭」模式執行 ---
# headless 模式會被 Cloudflare 判定為機器人（實測 API 路徑一律 403），
# 有頭模式的信任分數高很多。無 GUI 的容器裡靠 xvfb 提供假的顯示器。
# xauth 是 xvfb-run 的必要相依，slim image 不會預裝。
xvfb
xauth
